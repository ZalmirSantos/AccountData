# Account Data Manager

A simple banking/account management system developed in C#.

## 📌 About the Project

This project was created to practice C# fundamentals, object-oriented programming concepts, and class structure organization.

The application simulates account data management through a console interface.

## 🚀 Features

- Create account records
- Store account information
- Display account details
- Basic data management
- Console-based interaction

## 🛠️ Built With

- C#
- .NET
- Object-Oriented Programming (OOP)
- Console Application

## 📂 Project Structure

- `Program.cs` → Main application flow  
- `AccountData.cs` → Account class and data structure

## ▶️ How to Run

Open the project in Visual Studio and run the application.
